# Setup Guide

## Environment

* VirtualBox
* Ubuntu Server
* Kali Linux
* Apache2
* MySQL
* DVWA
* Docker
* SafeLine WAF

## Setup Steps

1. Create Ubuntu and Kali Linux virtual machines.
2. Configure bridged networking.
3. Install Apache2 and MySQL.
4. Deploy DVWA.
5. Configure the DVWA database.
6. Change Apache listening port to 8080.
7. Configure local DNS resolution.
8. Generate self-signed SSL certificates.
9. Install SafeLine WAF using Docker.
10. Configure SafeLine as a reverse proxy.
11. Import SSL certificates into SafeLine.
12. Onboard DVWA application.
13. Validate HTTPS access.
14. Test SQL Injection detection.
15. Test HTTP Flood protection.
16. Configure custom deny rules.
