# Why SafeLine WAF?

For this homelab project, multiple Web Application Firewall solutions were evaluated before selecting SafeLine WAF.

## Reasons for Selection

### Self-Hosted Architecture

SafeLine allows complete control over traffic, logs, and configuration without relying on third-party cloud services.

### Ease of Deployment

Deployment is simplified through Docker and an automated installation process.

### Modern Threat Protection

SafeLine provides protection against:

* SQL Injection
* Cross-Site Scripting (XSS)
* Remote Code Execution (RCE)
* Path Traversal
* HTTP Flood Attacks
* Automated Bot Activity

### User-Friendly Interface

The management dashboard provides visibility into:

* Attack events
* Traffic statistics
* Security policies
* Rule management

### Learning Objectives

SafeLine was selected because it enables hands-on experience with:

* Reverse proxy architecture
* Web application security
* Attack detection
* Security monitoring
* WAF policy management

This made it an excellent choice for a cybersecurity homelab focused on both offensive testing and defensive controls.
